# Shiftland identity

Shiftland's mark is a right-facing hare in a compact leap. The swept-back ears use diagonal cuts, the tail makes a small wedge, and the gap under the chest defines the leading paw. These features carry the gesture at small sizes.

[AppIcon.png](AppIcon.png) is the 1100 × 1100 RGBA app master for Finder and the native About panel. It uses a warm ivory hare on an aubergine tile that occupies roughly 82% of the canvas width. The build resamples it into the macOS icon set. The 18 × 16 point menu-bar template reproduces the same profile in a single color supplied by macOS.

The reference was the owner's selected hare from the previous concept round. The built-in ImageGen tool redrew the silhouette and adjusted the tile's placement. The final canvas crop removed only surplus transparent padding. The compact study was selected after reviewing both studies at 16, 32 and 64 pixels. The stepped-belly study produced a hard interruption in the silhouette and an awkward folded hind foot.

## Small icon

[AppIcon-16.png](AppIcon-16.png) and [its 2× counterpart](AppIcon-16@2x.png) are drawn for the 16-point slot. They open the space between the ears and give the feet more weight and clear separation from the tile edge. The full-size master continues to supply the larger icon sizes.
