# Product

<!-- impeccable:product-schema 1 -->

## Platform

macOS

## Users

The first user is the owner of this Mac. They switch between numbered workspaces throughout the day on a MacBook and an external monitor.

## Product purpose

Put the workspace switcher and the settings for workspaces, displays and shortcuts in one native app. OmniWM owns window tiling, routing and workspace state. This app owns presentation and the controls used to configure that experience.

## Brand Commitments

The product name is Shiftland.

## Operating context

The pilot uses macOS 15.5 and the installed OmniWM 0.5.1. The original SketchyBar pilot is the reference for the workspace bar's visuals, placement and interaction.
