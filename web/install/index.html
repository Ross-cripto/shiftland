Install Shiftland on macOS

Shiftland runs on Apple Silicon and Intel Macs with macOS 15 or later. It checks your Mac when you open it and guides you through connecting the workspace bar.

Download Shiftland

Open Shiftland for the first time

  1. Open the disk image, then drag Shiftland to Applications.
  2. Open Shiftland from Applications. The current release is signed ad hoc. If macOS blocks it because it lacks Apple notarization, open System Settings → Privacy & Security, click Open Anyway for Shiftland, and confirm.
  3. Follow the connection window. If it asks for OmniWM, install the recommended version, grant its requested permissions, and enable IPC in its settings.
  4. When the bar appears, click a workspace to switch to it. If you have a workspace labeled 0, press ⌥0 to jump to it.

See Apple’s first-launch instructions for help with macOS approval.

Which OmniWM version works with my Mac?

To check your macOS version and chip or processor, choose About This Mac from the Apple menu.

Apple Silicon with macOS 26 or later
These systems meet the requirements of the current OmniWM release.
Apple Silicon with macOS 15, or Intel with macOS 15 or later
The OmniWM 0.5.1 download includes both architectures and requires macOS 15 or later. Shiftland has been tested with OmniWM 0.5.1 on an Apple Silicon Mac running macOS 15.5.

If the bar is missing

Check that OmniWM is open and that IPC is enabled. Confirm that Displays have separate Spaces is enabled in System Settings under Desktop & Dock. If Shiftland shows a connection window, follow the step it recommends for this Mac.
